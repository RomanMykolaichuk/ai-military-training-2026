# AI Military Training 2026

Матеріали курсу підвищення кваліфікації за напрямом використання елементів технологій штучного інтелекту у військовій сфері.

## Навчальна платформа

Статична інтерактивна платформа для проведення курсу:
- матеріали 13 навчальних занять;
- візуальні моделі та наочні приклади;
- інтерактивні вправи;
- Prompt Builder;
- короткі самоперевірки;
- локальне збереження прогресу;
- окрема сторінка розкладу.

Технології: **HTML + CSS + Vanilla JavaScript**. Backend не потрібен.

GitHub Pages після злиття в `main`:

https://romanmykolaichuk.github.io/ai-military-training-2026/

## Поточний MVP

Повністю інтерактивно реалізоване еталонне заняття:

**2/1 — Основи роботи з LLM**

Решта занять уже доступні через єдиний шаблон і послідовно наповнюватимуться контентом.

## Розклад

Курс: **21–25 вересня 2026 року**, №10356, базовий рівень.

Інтерактивний розклад після публікації:

https://romanmykolaichuk.github.io/ai-military-training-2026/schedule.html

## Структура

```text
index.html                  # головна навчальної платформи
lesson.html                 # reusable lesson page
schedule.html               # інтерактивний розклад
assets/css/site.css
assets/js/app.js
data/course-data.js         # структура курсу + контент
docs/PLATFORM_SPEC.md       # ТЗ та карта розвитку
```

## Принцип розроблення

Core-платформа не залежить від зовнішніх AI API. Реальні AI-сервіси можуть додаватися пізніше як опційні інтеграції.

У навчальних прикладах використовуються лише синтетичні / нечутливі дані.
